# /jevai: Jev by TypeSafe

"JEV AI" / "jev api" from the user means **Jev, TypeSafe's System One model** (console: https://console.typesafe.ai/home). Jev does not write text. It returns typed answers with probabilities: `score` (rubric levels), `noul` (yes/no probability), `choice`, `box` (image region). Use it as a judge or classifier; keep the writing and the logic in code or in Claude.

## Key

Stored in `~/.claude/secrets/typesafe.env` as `TYPESAFE_API_KEY=...` (outside every repo). Never print it, never write it into a project file, a commit, or an artifact. The env var `TYPESAFE_API_KEY` overrides the file.

## Run

```bash
python ~/.claude/skills/jevai/jev.py score a.md b.md     # one text per non-empty line; prints table + means per file
python ~/.claude/skills/jevai/jev.py raw request.json    # any System One body: {"state":..., "model":"jev-latest", "questions":{...}}
```

`score` asks three questions per paragraph:
- `human` Score 0-3: machine-generated ... reads like a person (student to lecturer)
- `ai` Noul: probability the text was generated by an AI model
- `polite` Score 0-3: tone fit for a student replying to an examiner

For other judgments write a `raw` request. Question shapes: `{"type":"score","instructions":"...","criteria":["level 0","level 1",...]}`, `{"type":"noul","instructions":"..."}`, `{"type":"choice","instructions":"...","criteria":{"key":"description",...}}`. Batch many questions in one request.

## Network note (this Windows machine)

## How to report

Jev's numbers are one model's calibrated judgment, not proof. Pair them with a concrete measure where one exists (for Indonesian prose, `humanizer-indonesia`'s `scripts/metrik.py`). Docs: https://docs.typesafe.ai/llms.txt
