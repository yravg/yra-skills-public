# Evidence matches the claim

**When:** you say something works, fails, or is unchanged.

Record the command, the revision, the fixture, and the output you actually saw. A screenshot supports a layout claim. It does not prove a saved write, an authorization check, or a charge.

Rules:
- An unrun test is untested.
- A green run of another commit is not evidence for this diff.
- Do not invent a failing baseline.
