# Three kinds of knowledge

**When:** a term, a rule, or a relationship is in play.

Keep the glossary, the domain model, and the codebase standards apart. The glossary says what a concept means. The model says how concepts relate and which invariants hold. Standards say how this repo implements them.

Rules:
- Reuse a term the repo already accepted.
- Record an alias when old code uses another name.
- Do not rename an API, a table, or a file unless the user asked for that rename.
