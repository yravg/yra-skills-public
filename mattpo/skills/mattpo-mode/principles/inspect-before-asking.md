# Inspect before asking

**When:** you are about to ask the user a question.

Read the repo, the glossary, the ADRs, the standards, and the tests that could answer it. Cite the path and the revision. Ask only what those sources do not settle.

Rules:
- Label a conclusion as an inspected fact, an owner report, an assumption, a contradiction, or an open decision.
- One question, then wait.
