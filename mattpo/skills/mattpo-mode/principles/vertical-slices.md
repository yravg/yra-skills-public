# Vertical slices

**When:** the work is larger than one sitting.

Each ticket demonstrates one user outcome through the layers it needs. Name blockers, exclusions, and how to tell it works. A wide migration says expand, migrate, then contract. Do not pretend each mechanical step is a finished flow.

Rules:
- A small task stays in this chat.
- Do not split one outcome into a frontend ticket, an API ticket, and a database ticket that none of them can demo alone.
