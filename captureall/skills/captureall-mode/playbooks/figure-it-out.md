### Figure it out

**Design a bespoke playbook when no listed playbook fits the goal, or the goal spans three or more of them, then run it.**

1. Write the goal and a done check someone could measure.
2. List what is known and unknown about the target and the clone. Settle the unknowns that decide the plan with a quick capture or probe (`../principles/observe-dont-ask.md`), not a question.
3. Read the playbooks whose parts apply. Borrow their steps rather than inventing new ones.
4. Write the bespoke steps: numbered, each ending in a check, ordered so each step lands visible progress. Mark which steps go to delegates.
5. Name the skills each step uses (web, app, grab, reanimate, match, parity, pack) and the licence class of the items touched.
6. Put the steps into the task list and save them to the checkpoint file, so a resumed run follows the same plan.
7. Run the steps. Revise the plan when a check fails, and record why in the checkpoint.
8. Measure the done check. Run the `captureall` QA gate.

**Reply:** the goal, the bespoke steps in one line each, the done check result with evidence, what was not done and why, and open decisions.
