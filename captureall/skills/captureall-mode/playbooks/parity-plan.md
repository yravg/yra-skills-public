### Parity plan

**Turn a capture of a target into a gap list, a roadmap and a handoff for making a clone "the same".**

1. Make sure a current capture of the target exists (site crawl or element capture); else run one first.
2. Capture the clone the same way (same pages, variants, viewports).
3. Read `../../captureall-parity/SKILL.md` and build the gap list per area: IA and counts, landing, item pages, preview bar and stage controls, themes, tokens, fonts, motion, states, responsive, a11y, copy.
4. For each gap: target evidence, clone evidence, licence class, proposed fix, size (S/M/L).
5. Write the roadmap and handoff files (paths and formats in the parity skill) in the clone's repo.
6. Order the steps so each lands visible progress; mark Pro/gated items "own implementation from description".
7. Run the `captureall` QA gate.

**Reply:** gap count per area, top gaps with evidence, roadmap and handoff links, open questions for Enrico.
