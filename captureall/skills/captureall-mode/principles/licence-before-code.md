# Licence before code

**When:** before any captured code, CSS, markup or asset is reused, ported or published.

Classify every item into one licence class first, and record the class in the inventory. The class decides what may be reused.

Rules:
- **Free / open (MIT, Apache, CC BY):** code the site shows publicly may be ported. Keep the licence file and the credit line in the port.
- **Pro / paid / gated:** capture the rendered preview, the description and the behaviour only. Never fetch hidden registry or API endpoints, never unlock a gate, never use the user's session to pull gated source, never copy its code, CSS or markup. A clone of it is an own implementation written from the description and observed behaviour.
- **Own:** the user's own product; anything goes.
- If the user says the Pro tier is now theirs (a bought licence that allows publication), ask for the licence terms or the file that records it before treating Pro items as reusable, and note the source in the inventory.
- Unknown licence: treat as Pro until shown otherwise.
