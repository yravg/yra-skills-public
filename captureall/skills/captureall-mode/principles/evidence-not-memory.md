# Evidence not memory

**When:** saying two things match or differ, counting items, or describing how a target looks or moves.

Every match, difference and count comes from a capture made in this run: a capture file, a screenshot, a measured value. Sites change; memory of a site is not evidence.

Rules:
- "Same as the target" needs a side-by-side: same viewport, same theme, same moment of the animation.
- Counts (items per group, pages per section) come from the IA capture, not from a guess at the sidebar.
- When a capture is missing for a claim, say "not checked" instead of asserting.
