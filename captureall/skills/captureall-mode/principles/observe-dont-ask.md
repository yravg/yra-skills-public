# Observe, don't ask

**When:** about to ask Enrico "which approach?", "is it the same?", "does it animate like that?", "which width?" or "will this work?".

If a measurement, a capture, a build or a quick prototype can answer the question, the question is not his. Run the check and let the result decide.

Rules:
- Facts about the target (layout, timing, text, which items exist, what a variant changes) come from capturing it.
- Facts about the clone (does it build, does it match, does it render) come from building and matching it.
- Two possible approaches → try the cheaper one on one item, measure with `captureall-match`, keep the winner.
- Ask only for the Always-pause list in the mode, a licence record, or a real taste call no measurement settles (for example which of two equally faithful designs he prefers).
- When you decide a call for him, report it with the evidence and what he could tell you to do instead.
