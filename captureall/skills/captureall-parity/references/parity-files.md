# Parity files

## Roadmap (`docs/roadmap/<feature>.md`, or the repo's plan folder)

Written once; changed only when scope changes.

```markdown
# <Clone> parity with <target>

Goal: <one sentence, what "the same" means and what stays ours (brand, mascots, own Pro implementations)>.
Target capture: <workbook / pack path, capture date>.
Licence: free/open items <n> (ported with credit), Pro/gated items <n> (own implementation from description).

## Gaps
| Area | Gap | Evidence | Size |
|---|---|---|---|

## Steps
1. <step> — acceptance: <what a reviewer sees on which URL>.
2. ...

## Order
<why this order: visible progress first, shared pieces before their users>.

## Open questions
- <question> — who answers.
```

## Handoff (`docs/handoff/<feature>.md`)

Rewritten at the end of every session and after every finished step.

```markdown
# <Clone> parity — handoff

Roadmap: <link>. Target capture: <link>.

| Step | State | Evidence |
|---|---|---|
| 1 <name> | done / open / in progress / blocked | <commit SHA, URL, sweep result> |

## Open questions
- <question> — <who must answer>.

## Known failures
- <what, where, since when>.

## Next step
<exact next action, with file and command>.
```
