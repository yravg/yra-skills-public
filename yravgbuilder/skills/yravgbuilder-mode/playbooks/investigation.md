### Investigation

**Answer a read-only question about the stack, a screen or a port.**

1. Restate the question and what would answer it.
2. Read the code and docs that hold the answer (graft or grep first, then the named spans).
3. Run only read-only checks (tests, scans, renders). Edit nothing.
4. Answer with evidence: file:line, command output, numbers.

**Reply:** the answer first, then the evidence, then what was not read or run.
