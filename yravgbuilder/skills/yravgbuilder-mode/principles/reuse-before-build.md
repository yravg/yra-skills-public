# Reuse before build

**When:** a screen, component, helper or engine function is about to be written.

Search the repo, then the yravg catalogue, then the platform, before writing new code. Copy the real source; never rebuild from a picture or memory.

Rules:
- Name what you searched and what you found in the reply.
- Each new component carries a one-line reason it could not be reused.
- A look-alike of a catalogue piece is a defect, even when it looks right.
