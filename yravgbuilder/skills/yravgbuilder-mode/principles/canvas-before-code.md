# Canvas before code

**When:** a big feature, a redesign or a parity port of a reference product starts.

Coverage matrix and a canvas of every screen in the real chrome come first. Build after the owner signs off.

Rules:
- Every rebuilt board has a working Before / After toggle.
- Keep the app's real chrome (screenshot slices); never redraw it.
- Small change to one existing screen: skip the canvas, show a Before/After pair instead.
