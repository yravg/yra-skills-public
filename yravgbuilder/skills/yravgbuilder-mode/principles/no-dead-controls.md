# No dead controls, none removed

**When:** a control is added, restyled, moved or dropped.

Every visible control works. No control disappears for looks.

Rules:
- A stub button is not shown, or is disabled with an owner-agreed tooltip.
- Moving a control behind a fold, tab or overflow menu is fine; deleting it needs the owner.
- A removal or rename is recorded with its reason in the control registry if the app has one.
