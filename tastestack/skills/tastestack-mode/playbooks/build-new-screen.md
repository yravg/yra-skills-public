### Build new screen

**Go from a brief to a screen that passes the gate.**

1. Read the brief and the decision log. State the users, the jobs and the states.
2. Choose the direction with `tastemaker-direction`; write the brief with `tastemaker-brief` if none exists.
3. Confirm tokens exist (`tastemaker-tokens`). Add missing ones once, in the token file.
4. Build with `tastemaker-components`, tokens only, every state drawn.
5. Run the guard loop (`tastemaker-guard`) until it is clean.
6. Critique with the impeccable references and fix P0-P2.
7. Run the `tastestack` gate.

**Reply:** the files, the direction chosen and why, the scan score, the critique scores, the states drawn, what was not viewed.
