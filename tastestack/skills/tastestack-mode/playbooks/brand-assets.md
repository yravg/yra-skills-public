### Brand assets

**Produce banners, slides or identity assets through the tastemaker leaves.**

1. Read the brand guidelines if they exist; otherwise run `tastemaker-brand` first.
2. Pick the leaf: `tastemaker-banners`, `tastemaker-slides` or `tastemaker-identity`.
3. Use only marks and fonts with a known source and licence. Add a NOTICE line for each.
4. Deliver three real directions for banners, as the leaf requires.
5. Export, then view each file.
6. Run the slop scan and the contrast script on the palette.
7. Run the `tastestack` gate.

**Reply:** the files, the directions offered with a recommendation, the sources and licences, what was not viewed.
