### Product mock

**Make a faux product UI or an animated demo that looks real.**

1. Read the `stageshow` skill and its references (craft, framing, review, verify).
2. State what the mock must show and where it will be used.
3. Use sample data, labelled. No invented logos or results.
4. Build the scene. Match the project's tokens and fonts.
5. Judge it against the stageshow review and verify references.
6. Run the slop scan on the output. Render it and view every frame or state.
7. Run the `tastestack` gate.

**Reply:** the files, how to run or open the mock, the sample labels used, the scan score, what was not viewed.
