### Upstream sync

**Pull updates for impeccable, tastemaker and stageshow without breaking the plugin.**

1. Read `../tastestack-sync/SKILL.md`.
2. Run the check. If nothing is newer, report that and stop.
3. Show the user which upstreams are newer.
4. Ask the user before applying. This is on the Always-pause list.
5. Apply. If a licence change is refused, do not work around it; name the file.
6. Run the sync tests and the plugin checker.
7. Confirm the own skills (mode, core, help, sync) are still present.

**Reply:** upstreams updated with old and new commit, file counts, any refusal, the test result.
