# One tool per job

**When:** you pick which of impeccable, tastemaker or stageshow to use.

Each tool owns one job. Do not ask one tool for another's work.

Rules:
- Scan for slop, tokens, components, brand: tastemaker.
- Critique, polish, audit vocabulary, layout and type judgement: impeccable.
- Faux product UI and demo motion: stageshow.
- A review combines them in the order the core skill gives. Say which tool each finding came from.
