# Licences and attribution stay with assets

**When:** you vendor, fetch, copy or sync anything from outside the project.

The licence file and the attribution travel with the asset.

Rules:
- `vendor/` stays verbatim. Never edit it.
- A sync that sees a licence file changed or missing is refused. Read the file; the owner decides.
- A logo or font copied into a project gets a NOTICE line with its source.
- Do not apply an upstream sync without the owner's yes.
