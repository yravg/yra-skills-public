# Diff, don't rewrite

**When:** a screen already exists and the owner has made decisions on it.

Change the smallest part that fixes the finding. Keep every control, story and owner decision.

Rules:
- Read the project's decision log before you edit. A decision outranks your taste.
- Never drop a control for looks. If it must move, it moves; it does not vanish.
- Do not touch generated build outputs; the lead rebuilds them.
- If a finding conflicts with a decision, report it and leave the screen as it is.
